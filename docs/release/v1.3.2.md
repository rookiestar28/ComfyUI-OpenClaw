# ComfyUI-OpenClaw v1.3.2

This maintenance release aligns graph editing, sidebar layout, and development tooling with
the refreshed ComfyUI host contracts.

## Host compatibility

- ComfyUI source `7c4390a6` (project `0.43.0`) was qualified with its bundled frontend
  `1.57.6` and standalone frontend release `1.60.0` in an isolated CPU host on 2026-11-01.
- Each frontend passed all fifteen browser cases without skips or retries, including native
  sidebar resizing, tab handoff, model-control interactions, promoted widgets, and graph replay.
- The later frontend source checkout, either Desktop surface, and the older ComfyUI tag with
  a different bundle remain separate, unexecuted subjects. No GPU or provider generation was
  part of this host campaign.

See the [compatibility matrix](compatibility_matrix.md) for exact anchors and evidence scope.

## Graph editing and replay

- Complete node IDs, including IDs containing colons, take precedence over subgraph-path
  interpretation. Numeric and ordinary nested-graph compatibility paths remain supported.
- Shared subgraph definitions are resolved through their instance paths instead of choosing
  an arbitrary instance. Ambiguous IDs or targets fail before any widget values are written.
- Parameter Lab edits and replay preserve the intended promoted-widget and execution context.

## Sidebar and Settings

- Native panels retain host-owned width allocation and splitter behavior. Switching to another
  sidebar tab preserves the host's current width.
- Headers, tabs, Parameter Lab, and Settings model controls adapt to narrow native panels.
  Model selectors, refresh controls, and custom-model inputs remain usable and synchronized.
- Older sidebar hosts retain the legacy layout fallback.

## Development tooling

- Node.js must satisfy `^20.19.0 || ^22.12.0 || >=24.0.0`, matching the locked Vite/Vitest
  requirements. Node.js 24 is recommended for local development.
- Preflight, full-test scripts, pre-push, and direct npm test commands check the shared policy
  before starting dependency, bootstrap, or browser work. Dependency versions are unchanged.
- This is a development/test requirement; using the installed custom nodes does not require
  installing Node.js.

## Upgrade notes

Update the custom-node pack through ComfyUI-Manager or Git, restart ComfyUI, and reload the
browser. No configuration or storage-schema migration is required. Previously saved targets
that are ambiguous in a shared subgraph must be selected again from the intended instance.

OpenClaw continues to use bounded `/history` and `/view` output access; direct Asset API
adoption remains deferred. Desktop runtime qualification is tracked separately.
