# ComfyUI-OpenClaw v1.3.6

This maintenance release tightens the pack code-safety check and removes code patterns that
automated source scanners misread, without changing runtime behavior.

## Pack code safety

- Pack import and registry quarantine verification reject Python members that call the
  dynamic-execution functions. The check now also catches such a call written with whitespace
  between the function name and its parenthesis, which it previously missed.
- Every pack that was rejected before is still rejected, with the same message. A pack that
  only passed because of that whitespace is now rejected.

## Operator doctor

- The `pre-commit` availability check asks the import system whether the package can be found
  instead of importing it, so running the doctor no longer executes the package's startup code.
  Results are unchanged for a working or a missing installation.

## Source scanner findings

- A variable name in the Slack connector settings and the pack check's own deny-list were read
  by automated source scanners as privilege escalation and dynamic execution. Both were
  rewritten without changing behavior.

## Upgrade notes

Update the custom-node pack through ComfyUI-Manager or Git and restart ComfyUI. No
configuration or storage-schema migration is required. Host compatibility is unchanged from
v1.3.5.
